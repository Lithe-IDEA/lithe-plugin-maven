# Maven 1.0.1

## 中文

- Spring Boot 应用和在 POM 里写明主类的 Java 应用自动出现在标题栏的运行配置里，可以直接运行。
- Spring Boot 应用可以调试：点调试后服务以等待调试器的方式启动，Java 调试器自动连上（需要安装 Java Support 插件）。
- POM 没写主类的 Java 类也能运行：打开带 `main` 方法的类，标题栏选“当前文件”点运行，会编译模块后运行它，并保存为以类名命名的运行配置，之后可以编辑参数。

### 兼容性

需要 Lithe 桌面端 0.8.5 及以上（宿主需支持 `buildProviders: 1`）。更早的桌面端无法安装此版本，会继续使用 1.0.0；先升级桌面端即可获得新版插件。读取项目工具可能执行项目代码及下载依赖。

---

## English

- Spring Boot applications and Java applications whose POM names a main class now appear in the title bar's run configurations and run directly.
- Debug Spring Boot applications: the service starts waiting for a debugger and the Java debugger attaches automatically (requires the Java Support plugin).
- Run a Java class whose main class the POM does not name: open a class with a `main` method, choose Current File in the title bar and press Run. Lithe compiles the module, runs the class and saves it as a run configuration named after the class, whose arguments you can edit.

### Compatibility

Requires Lithe desktop 0.8.5 or later (the host must support `buildProviders: 1`). Earlier desktop versions cannot install this version and keep 1.0.0; upgrade the desktop app first to get it. Reading project tools may execute project code and download dependencies.
