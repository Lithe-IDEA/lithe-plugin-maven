0.0.1 是按插件契约 v0 重新发布的首个版本。

功能：
- 识别工作区最外层的 `pom.xml`，`<modules>` 组成模块树。
- 生命周期 `clean` 到 `deploy`，可对整个反应堆或单个模块运行；每个模块的插件目标按 `Plugins › <前缀>` 分组。
- 运行模块、测试类或单个测试方法，读取 Surefire/Failsafe 的 JUnit XML 报告。
- 编译输出里的 `[ERROR]`、`[WARNING]` 显示为问题。
- 整个反应堆或单个模块的依赖树，反应堆内未安装的兄弟模块也能解析。
- 插件设置 Maven executable；构建选项 JDK (JAVA_HOME)、Profiles、Settings File、Local Repository、Offline、Skip Tests。
- 新建项目：Maven（可选 Java release 8、11、17、21、25）和 Maven Archetype。
- 插件没有后端进程：读取项目和依赖是 `plugin.json` 声明的 Maven 命令，由 Lithe 运行，随包的 Maven 扩展只读取反应堆。

权限：`process.build`、`project.generate`。

兼容性：
- 只能装进新版 Lithe 桌面端（`desktop-v*` 预发布），旧版 macOS Lithe 无法安装。
- 本版本是预发布，Lithe Store 的自动追踪会跳过它。
