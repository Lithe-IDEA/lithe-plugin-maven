0.1.3 自 0.1.2 以来的变化：

- 移除宿主已删除的 `buildSystems.languageImport` 清单字段（新版 Core 严格校验会拒绝它）；改为导出插件函数 `languageImport.settings`，由插件后端（`--plugin-backend`，Java）按 `.mvn/maven.config` 的 `-s`、`-gs`、`-o` 向 Java Support 提供 Maven 导入设置。
- 接手 Java Support 的 Maven 新建项目入口：新增 Maven 项目生成器、Maven Archetype 生成器及项目模板（`projectGenerators`）。
- 清单新增 `backend: 2`、`pluginFunctions: 1`、`projectGenerators: 1` 要求，权限新增 `backend.launch`、`project.generate`、`workspace.metadata`。
- 包含 0.1.2 的 litheLogging 1 结构化诊断，以及直接编译 `vendor/` 下官方 Java SDK 源码。

兼容性：
- 旧版 Lithe（稳定版 0.6.7）没有 `pluginFunctions 1`，会拒绝安装本版本；Store 条目逐项复制 `requires`，让稳定版继续选择 0.1.1。0.1.1 仍声明 `languageImport`，因此新版 Core 不再接受 0.1.1，需要升级到 0.1.3。
- 本版本不再声明 `languageImport`。仍读取该字段的旧宿主（例如 0.6.7）在启用 0.1.3 后无法把 Maven 设置带入 Java 导入。
