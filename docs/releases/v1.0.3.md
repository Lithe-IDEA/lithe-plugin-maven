# Maven 1.0.3

## 中文

- 从当前 Java 文件、识别到的入口或保存的 Maven 应用配置启动调试时，Maven 会准备项目的运行类路径，桌面端使用 Java 调试器连接应用。

### 兼容性

此版本需要支持 `buildSystems: 2` 和 `buildProviders: 1` 的 Lithe 桌面端。请先升级桌面端，并安装提供 Java 调试器的 Java Support 插件。Lithe 0.8.12 可继续使用 Maven 1.0.2。

---

## English

- Debug from the current Java file, a discovered entry point, or a saved Maven application configuration. Maven prepares the runtime classpath and Lithe connects the Java debugger to the application.

### Compatibility

This release requires a Lithe desktop host that supports `buildSystems: 2` and `buildProviders: 1`. Upgrade Lithe and install Java Support for the Java debugger. Lithe 0.8.12 can keep using Maven 1.0.2.
