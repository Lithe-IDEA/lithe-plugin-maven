# Maven 0.2.1

## 中文

- 新增 Windows ARM64 和 x64 安装包（`maven-build-0.2.1-windows.zip`），与 macOS、Linux 包逐字节相同，兼容现有插件契约 v0 与 Lithe 桌面预览版。
- Windows 上依次使用设置里的 Maven、项目的 `mvnw.cmd`、`MAVEN_HOME\bin\mvn.cmd` 和 `PATH` 上的 `mvn.cmd`；最低支持的 Maven 仍是 3.6.3。
- 修复 Windows 上按路径匹配反应堆项目：Maven 只规范化子模块路径，工作目录大小写不同或带 8.3 短名时，模块的父项目和单模块依赖树会找不到项目。
- 保留已支持平台；Windows x64 由原生 CI 运行真实 Maven 命令，ARM64 尚未做原生验证。

---

## English

- Add Windows ARM64 and x64 packages (`maven-build-0.2.1-windows.zip`), byte-identical to the macOS and Linux packages, for the existing plugin contract v0 and Lithe desktop preview.
- On Windows, use the configured Maven, the project's `mvnw.cmd`, `MAVEN_HOME\bin\mvn.cmd`, then `mvn.cmd` on `PATH`; the minimum supported Maven is still 3.6.3.
- Fix matching reactor projects by path on Windows: Maven canonicalizes only module paths, so a working directory with different case or 8.3 short names lost module parents and single-project dependency trees.
- Keep existing platforms; native CI runs real Maven commands on Windows x64, and ARM64 is not natively verified yet.
