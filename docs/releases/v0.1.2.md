0.1.2 的变化：

- 构建后端接入 litheLogging 1：关键请求成功记 INFO、失败记 ERROR，带耗时和稳定分类，写入 Lithe 日志窗口的 `plugins/io.github.lithe-idea.maven-build/host` 通道；取消不记失败。
- 没有 `--state` 目录、快照保存失败、读取期间项目发生变化时各记一次 WARN `degraded`。Maven 失败只由 SDK 记录一次 ERROR，不再重复打印构建输出；源码、凭据、环境变量和构建输出不进入日志。
- 后端直接编译 `vendor/` 下官方 Java SDK 的源码（逐文件 SHA-256 校验），不再下载 SDK JAR；安装包附带 `SDK-LICENSE`。
